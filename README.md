# KJPP-HJAR Landing Pages

This repository contains the landing pages for the **KJPP-HJAR** website, built with Vue 3 and Vite.

## Project Purpose

The project is focused on:
- Presenting KJPP-HJAR services and profile information.
- Providing fast, responsive landing page experiences.
- Supporting future expansion of static and campaign-based pages.

## Tech Stack

- Vue 3
- Vite
- TypeScript
- ESLint

## Recommended IDE Setup

- [VS Code](https://code.visualstudio.com/)
- [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar)
- [TypeScript Vue Plugin (Volar)](https://marketplace.visualstudio.com/items?itemName=Vue.vscode-typescript-vue-plugin)

## Project Setup

```sh
npm install
```

## Run in Development

```sh
npm run dev
```

## Build for Production

```sh
npm run build
```
